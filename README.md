# Telegram-бот турагентства «Попутный ветер»

Учебный проект: бот **вымышленного** коммерческого предприятия (турагентство, Астана) с ИИ-консультантом.

## Что умеет бот
- 🌍 **Туры** — каталог из 6 направлений с ценами «от».
- 📝 **Заявка** — пошаговая заявка на подбор тура (направление → даты → гости → имя → телефон → подтверждение). Заявка сохраняется в `requests.jsonl` и, если задан `MANAGER_CHAT_ID`, пересылается менеджеру.
- 📞 **Контакты** — адрес, часы работы, телефон.
- 💬 **ИИ-консультант Лина** — отвечает на свободные вопросы о турах и условиях, подбирает направление. На посторонние темы вежливо отказывает.

## System prompt
Лежит в файле [`system_prompt.txt`](system_prompt.txt). При запуске в него подставляются каталог туров и контакты агентства из `bot.py` (метки `{{КАТАЛОГ}}` и `{{КОНТАКТЫ}}`), поэтому ИИ отвечает строго по данным каталога.

В промпте: роль и стиль, данные о компании, условия, список того, что бот делает и чего не делает, правила отказа на посторонние темы и защита от попыток обойти инструкции.

## Запуск
1. Python 3.10+ (сторонние пакеты не нужны).
2. Скопируйте `.env.example` в `.env` и заполните `BOT_TOKEN` (от @BotFather) и `OPENROUTER_API_KEY` (openrouter.ai).
3. `python -X utf8 bot.py`

ИИ работает через OpenRouter на бесплатных моделях: бот перебирает цепочку моделей, если одна перегружена. Секреты и файл заявок (`requests.jsonl`) в git не попадают.
