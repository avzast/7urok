# Проект 7urok

Telegram-бот вымышленного турагентства «Попутный ветер» (Python, только стандартная библиотека). Учебное домашнее задание: проверяется system prompt.

## О пользователе
- Пользователя зовут Алексей. Общаемся по-русски.

## Устройство
- `bot.py`: long polling; кнопки «Туры», «Заявка», «Контакты»; свободные вопросы идут ИИ (OpenRouter, цепочка бесплатных моделей).
- Заявка через JSON: модель по `extract_prompt.txt` достаёт поля, код проверяет (`check_field`, `validate`) и переспрашивает недостающее; результат в `requests.jsonl`.
- `system_prompt.txt`: system prompt с few-shot блоком `<примеры>`; метки `{{КАТАЛОГ}}`, `{{КОНТАКТЫ}}`, `{{МЕНЕДЖЕР}}`, `{{ТЕЛЕФОН}}` подставляются из данных в `bot.py`.
- `test_cases.md`: сравнение ответов до и после примеров (правда, дословные ответы модели).
- Репозиторий публичный: никаких секретов и персональных данных (`.env`, `requests.jsonl`) в коммитах.

## Запуск
- `python -X utf8 bot.py`
- Секреты в `.env`: `BOT_TOKEN`, `OPENROUTER_API_KEY`; необязательно `MANAGER_CHAT_ID`, `AI_MODELS`. Шаблон: `.env.example`.
